### Trabajo final - Proyecto integrador de Inteligencia Artificial

Este trabajo final integra los conceptos fundamentales vistos durante el curso. El objetivo es que cada grupo diseñe **una propuesta coherente de sistema de inteligencia artificial** basada en un caso de uso realista, demostrando comprensión de los conceptos centrales y la capacidad de relacionarlos dentro de un mismo sistema.

El proyecto **no busca implementar un sistema completo**, sino demostrar comprensión conceptual y capacidad de diseño: cómo los distintos componentes de la inteligencia artificial moderna pueden integrarse para resolver un problema concreto.

El trabajo debe mostrar que el estudiante comprende:

- el **pipeline completo de aprendizaje automático**.
- el papel de **modelos neuronales modernos**.
- el uso de **Transformers y modelos de lenguaje**.
- el potencial de **modelos multimodales y generativos**.
- el rol del **aprendizaje por refuerzo**.
- cómo estos elementos se integran dentro de **un sistema de IA real (MLOps)**.

#### 1. Objetivo del trabajo

Cada grupo debe seleccionar **un caso de uso de inteligencia artificial** (por ejemplo en ciencia, industria, educación, salud, robótica, logística, etc.) y diseñar una **arquitectura conceptual de sistema de IA**.

El proyecto debe explicar:

- qué problema se quiere resolver
- qué tipo de modelo sería adecuado
- cómo se integraría en un sistema real
- qué riesgos técnicos o éticos existirían
- cómo se evaluaría su funcionamiento

El trabajo debe demostrar **comprensión conceptual clara**, no solo enumeración de tecnologías.

#### 2. Modalidad de trabajo

El trabajo se desarrolla **en grupo**. Sin embargo, **cada estudiante debe subir su propia presentación individualmente.**

Esto significa:

- el proyecto se discute y se prepara en grupo
- pero **cada estudiante debe subir su propio archivo ZIP**

#### 4. Estructura obligatoria de la presentación

La presentación debe tener **entre 12 y 15 diapositivas**.

Se recomienda usar la siguiente estructura.

##### Diapositiva 1 - Título del proyecto

Debe contener:

- título del proyecto
- nombre del estudiante
- curso
- fecha

##### Diapositiva 2 - Caso de uso

Subsecciones:

- Problema que se desea resolver
- Contexto del problema
- Quién se beneficia
- Por qué la IA puede ayudar

##### Diapositiva 3 - Pipeline de aprendizaje automático

Subsecciones:

- Datos
- Modelo
- Evaluación
- Despliegue

Se puede usar el esquema:

Datos -> Modelo -> Evaluación -> Despliegue

##### Diapositiva 4 - Modelo base de aprendizaje profundo

Subsecciones:

- tipo de red neuronal (MLP, red simple, etc.)
- función de activación
- función de pérdida
- entrenamiento con gradientes
- optimizador

##### Diapositiva 5 - Transformers

Subsecciones:

- concepto de self-attention
- consultas, claves y valores
- multi-head attention
- positional encoding

Debe explicarse **por qué un Transformer sería útil o no en el problema.**

##### Diapositiva 6 - Modelos de lenguaje (LLM)

Subsecciones:

- tokenización
- ventana de contexto
- generación de texto

Debe explicarse:

- qué tareas realizaría el LLM
- cómo se utilizaría en el sistema

##### Diapositiva 7 - Alineamiento y agentes

Subsecciones:

- RLHF o aprendizaje basado en preferencias
- control de comportamiento del modelo
- LLM como agente
- uso de herramientas externas
- memoria de conversación

##### Diapositiva 8 - Visión computacional o multimodalidad

Subsecciones posibles:

- uso de imágenes
- Vision Transformers
- modelos texto-imagen
- CLIP o modelos multimodales

Si el proyecto **no requiere visión**, explicar por qué.

##### Diapositiva 9 - Modelos generativos

Subsecciones:

- generación de contenido
- generación de datos
- modelos de difusión (idea general)

Debe discutirse si los modelos generativos **aportan valor al sistema**.


##### Diapositiva 10 - Aprendizaje por refuerzo

Subsecciones:

- estado
- acción
- recompensa
- política

Debe explicarse si el problema **puede o no formularse como un problema de decisión.**

##### Diapositiva 11 - Sistema de IA y MLOps

Subsecciones:

- entrenamiento del modelo
- despliegue
- monitoreo
- reentrenamiento

También mencionar:

- costos
- latencia
- privacidad
- seguridad

##### Diapositiva 12 - Factibilidad del proyecto

Responder:

**¿Es factible construir este sistema en la práctica?**

Subsecciones:

- qué partes son fáciles de implementar
- qué partes requieren más recursos
- principales limitaciones


#### 5. Contenido esperado en cada sección

En cada diapositiva se espera **explicación conceptual clara**.

No se espera:

- código
- ecuaciones complejas
- implementaciones

Se espera que los estudiantes demuestren:

- comprensión de los conceptos
- capacidad de relacionar tecnologías
- razonamiento sobre cuándo usar cada modelo
